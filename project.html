Minty
2023.05 - 2023.06  (Team Project)
1/1
개인 상점 운영 및 중고거래를 지원하는 웹 기반 플랫폼입니다. 사용자 간 거래 기능과 관리자 운영 기능을 포함한 풀스택 웹 애플리케이션으로 개발하였습니다.

React 기반 컴포넌트 구조로 프론트엔드를 설계하여 재사용성과 유지보수성을 고려하였으며, REST API 기반으로 서버와 데이터를 연동하였습니다.

Spring Boot를 활용하여 백엔드 API를 구현하고, MySQL 데이터베이스 설계 및 CRUD 로직을 직접 개발하였습니다. 외부 API 연동을 통해 데이터 처리 및 시스템 간 통신 구조를 구현하였습니다.

주요 기능
사용자 : 상품 등록/판매, 시세 조회, 포인트 및 이벤트 시스템, 채팅 및 지역 채팅, 잔고 충전/출금
관리자 : 대시보드, 사용자/컨텐츠 관리, 마케팅 관리, 매출 통계, 고객지원 관리

상품 등록 및 주문 기능을 제공하는 쇼핑몰 웹 애플리케이션입니다. Spring Boot 기반으로 RESTful API를 설계하고, 상품·회원·주문 도메인 중심의 CRUD 기능을 구현하였습니다.

REST API 설계, 데이터베이스 스키마 설계, 서버-클라이언트 간 JSON 데이터 처리 흐름을 구현한 프로젝트입니다.
